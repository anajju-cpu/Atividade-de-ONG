# 🐾 Amor Animal

O **Amor Animal** é uma plataforma web desenvolvida para apoiar a causa animal, facilitando a adoção responsável, o resgate, a doação e o voluntariado.

---

## 🚀 Sobre o Projeto

O projeto foi estruturado com foco em uma navegação simples e intuitiva, permitindo que os usuários conheçam a iniciativa, visualizem animais disponíveis para adoção e se cadastrem para colaborar.
